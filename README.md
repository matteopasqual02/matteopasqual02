### 🧠 Kolmogorov-Arnold Networks (KANs) Lecture | *Project 2024*
* Studied and presented Kolmogorov-Arnold Networks (KANs), a spline-based alternative to MLPs inspired by the Kolmogorov-Arnold theorem, as part of the Numerical Analysis for Machine Learning course.
* Analyzed KANs' theoretical foundations and architectural differences from MLPs, covering learnable B-spline activation functions, training dynamics, and advanced techniques (sparsification, pruning, symbolic regression) for improved interpretability.
